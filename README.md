
# Student Management API

A RESTful Student Management API built using Node.js and Express.js. This project demonstrates API development, request handling, error handling, and API testing using Postman.

## Project Overview

The Student Management API is designed to manage student records through HTTP requests. It demonstrates backend development concepts, REST API principles, and error handling.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman
- Git and GitHub
- Visual Studio Code

## Features

- REST API development
- Student record management
- HTTP request and response handling
- Error handling and validation
- API testing using Postman
- Organized source code

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/divya-sri2014/Student-Management-API.git
```

### 2. Navigate to the project folder

```bash
cd Student-Management-API
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

Check the scripts in `package.json` and use the appropriate command. For example:

```bash
npm start
```

If your project uses a development script:

```bash
npm run dev
```

The API will run on the port configured in your project.

## API Testing with Postman

Postman is used to send HTTP requests and verify API responses.

Testing includes:

- Sending API requests
- Checking response status codes
- Validating response data
- Testing error-handling scenarios
- Verifying invalid requests and responses

The Postman collection is available in the `Postman/` folder.

## Error Handling

The project demonstrates error handling for API requests, including appropriate HTTP status codes and error responses for invalid or unsuccessful requests.

## How to Test

1. Clone the repository.
2. Install the required dependencies.
3. Start the API server.
4. Open Postman.
5. Import the collection from the `Postman/` folder.
6. Send requests to the running API and inspect the responses.
